# Анализатор успеваемости

Кумич Анна Александровна, группа 4СПИ

Консольная программа читает CSV-файл с баллами студентов и сохраняет статистику (количество, средний, минимальный и максимальный балл, средний балл по группам) в JSON-файл.

## Установка

1. Установить Python 3.12 и Poetry.
2. В папке проекта выполнить: poetry install

## Запуск

poetry run python main.py data/students.csv --output report.json

Формат CSV: столбцы student, group, score (балл от 0 до 100), кодировка UTF-8.
